# 機能と操作

## 独立した 2 体のマスコット

アプリは現在、2 つの別ウィンドウを起動します。

- 猫
- ペンギン

それぞれが独自の外周パス、曲がり角のタイミング、速度係数を持つため、常に同時に曲がることはありません。時間が経つほど自然にズレて動きます。

## マスコットモード

トレイから 4 つのモードを切り替えられます。

- `Running`: 2 体とも現在のディスプレイ外周を自動で歩きます。
- `Idle`: 2 体とも表示を維持したまま停止します。
- `Random`: 各マスコットがタイマーで `Running` と `Idle` を切り替えます。
- `Codex`: 2 体とも `.codex/state_5.sqlite` を参照し、Codex の最近の稼働量に応じて加速します。

マスコットウィンドウは常に最前面かつクリック透過なので、他のアプリ操作を邪魔しません。

## 速度調整

基準速度はトレイから切り替えられます。

- `Speed: Fast`
- `Speed: Medium`
- `Speed: Slow`

トレイから指定するのは共通の基準速度ですが、実際の移動速度には各マスコット固有の係数が追加でかかります。

## 背景イラスト

`Show Background` を使うと、マスコットの後ろに横長の背景イラストを表示できます。背景は非インタラクティブなので、他ウィンドウへのクリックを妨げません。

## トレイ操作

- トレイアイコンをダブルクリックすると、すべてのマスコットウィンドウをフォーカスを奪わずに再表示します。
- `Show` で隠れているマスコットを再表示できます。
- `Quit` でトレイ常駐ではなく完全終了します。

## 開発者メモ

- `main.js` は `MASCOT_WINDOW_CONFIGS` からマスコットごとに `BrowserWindow` を生成します。
- `index.html` は `window.location.search` を見て、素材、サイズ、速度係数を切り替えます。
- `Codex` モードでも、Codex 稼働量の参照は共有しつつ、各レンダラーは独立して移動を続けます。
