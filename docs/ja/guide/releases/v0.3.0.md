# v0.3.0 リリースノート

<img src="/release-header-v0.3.0.svg" alt="Desktop Pet Mitarashi v0.3.0 release header">

`v0.3.0` は、2 体のマスコット構成、Codex 連動アニメーション、docs 付きの配布フローをひとつのタグ付きリリースとしてまとめた最初の版です。

## ハイライト

- 猫とペンギンが独立したウィンドウで起動し、それぞれサイズ、速度係数、角の曲がり方を別々に持てるようになりました。
- 移動処理を画面下固定からディスプレイ外周追従へ拡張し、エッジへの吸着、角での旋回、向きに応じた表示切り替えに対応しました。
- `.codex/state_5.sqlite` の稼働状況を参照する `Codex Mode` を追加し、Codex の作業量に応じてマスコット挙動を変えられるようになりました。
- Windows / macOS では、トレイからログイン時起動を切り替えられ、対応環境では起動時に隠して開始できます。

## パッケージングと配布

- ビルドワークフローは、パッケージング前に semver タグを `package.json` へ同期するようになりました。
- タグ付きビルドでは引き続き Windows / macOS / Linux 向け成果物を作成し、GitHub Release に添付します。
- さらに VitePress ベースの docs サイトと GitHub Pages 公開ワークフローが追加され、ガイドとリリース情報を同じリポジトリから公開できます。

## ドキュメント面の更新

- 英語と日本語の両方で、はじめに、機能、ビルドとリリース手順を docs 化しました。
- リリースヘッダー画像を version 付きで管理し、docs ページと GitHub Release の両方から同じ `v0.3.0` アセットを参照できます。
