# Desktop Pet Mitarashi v0.3.0: 2体構成と Codex Mode、そして整ったリリース導線

<img src="/release-header-v0.3.0.svg" alt="Desktop Pet Mitarashi v0.3.0 release header">

`v0.3.0` は、Desktop Pet Mitarashi が「単体の小さなデスクトップおもちゃ」から、「育っていくデスクトップ companion project」へ一段進んだ版です。今回の更新では、マスコットが 1 体から 2 体になり、Codex の稼働状況に反応する `Codex Mode` が入り、さらに docs と配布の流れまで含めて release 体験が整いました。

## 画面の中に“生きた感じ”が増えた

いちばんわかりやすい変化は、猫がひとりではなくなったことです。`v0.3.0` では、猫とペンギンが別々の透明ウィンドウとして起動し、それぞれが少しずつ違うリズムで歩きます。

トレイからのモード変更は共有しつつ、角の曲がり方や速度係数は別々なので、見た目が機械的に揃いすぎません。この差が入るだけで、単なるループアニメーションではなく、作業空間に薄く乗る遊び心として感じやすくなります。

## 移動は“画面下の1本線”から“外周”へ広がった

これまでの流れでは、画面下を走る印象が強い構成でした。`v0.3.0` ではレンダラーの移動処理が大きく広がり、ディスプレイ外周への吸着、角での旋回、進行方向に合わせた向きの切り替えに対応しています。

この変更で、プロジェクト名どおりの「desktop pet」らしさがはっきり出ました。マスコットはもう下端の1本を往復するだけではなく、ワークスペースの縁そのものを歩く存在になっています。

## Codex Mode が“反応するマスコット”にした

もうひとつ大きいのが `Codex Mode` です。アプリは `.codex/state_5.sqlite` を読み、最近の Codex activity をもとにマスコット挙動へ反映します。

これによって、このプロジェクトは単なる汎用マスコットではなく、Codex を使って作業する人のための軽い companion という個性を持ちました。仕事の邪魔はせず、でも activity にだけはちゃんと反応する。この距離感がちょうどいい更新です。

## 配布まわりも一段きれいになった

今回の release は、見た目だけではなく、どう届けるかも改善しています。ビルドワークフローは push された tag から version を同期してからパッケージを作るようになり、成果物の版番号と公開 release の整合が取りやすくなりました。

さらに、英語・日本語対応の GitHub Pages docs が整ったことで、バイナリ配布と説明ページを同時に揃えられるようになりました。コードの中身と公開面を合わせて育てていける形になったのが `v0.3.0` のもうひとつの価値です。

## 検証

- `npm run docs:build`
- `npm run build:win -- --publish never`
- `v0.3.0` タグの GitHub Actions build が Windows / macOS / Linux で成功してから Release 本文を確定
