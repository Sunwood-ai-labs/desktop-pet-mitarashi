# v0.3.0 Release Notes

<img src="/release-header-v0.3.0.svg" alt="Desktop Pet Mitarashi v0.3.0 release header">

`v0.3.0` is the first release that packages the current two-mascot desktop experience, Codex-aware animation, and the new docs-backed delivery flow in one tagged build.

## Highlights

- Added two independent mascot windows so the cat and penguin can run with their own size, speed multiplier, and corner timing.
- Reworked movement to follow the outer edges of the current display, including edge snapping, turning, and directional pose changes.
- Added `Codex Mode`, which reads `.codex/state_5.sqlite` activity and adjusts mascot behavior from live Codex work.
- Added launch-at-login controls for Windows and macOS directly from the tray, with startup-hidden support where the platform allows it.

## Packaging And Delivery

- The build workflow now syncs the semver tag back into `package.json` before packaging release artifacts.
- Tagged builds continue to create Windows, macOS, and Linux artifacts and attach them to the GitHub Release.
- The repository now ships a VitePress docs site with a dedicated GitHub Pages workflow, so release notes and usage guides can be published alongside the app.

## Docs Surface

- English and Japanese docs now cover getting started, features, and build-and-release guidance.
- The release header artwork is versioned so both docs pages and GitHub Releases can reference the same asset for `v0.3.0`.
